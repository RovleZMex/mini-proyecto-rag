# src/generacion.py · reglas del prompt (extracto)

1. Use only facts stated in the excerpts.

   Do not use outside knowledge about the game.

2. Always state which patch each fact comes from.

4. If the excerpts do not contain the answer, reply:

   "The provided patch notes do not contain

    this information."

5. If they contain only part, say what is missing.

6. Cite the excerpts you used, like [2].

Por qué estas reglas

Regla 1. Haiku conoce el juego hasta su fecha de corte; sin la regla podría rellenar huecos con valores viejos.

Regla 4. Una frase fija permite medir automáticamente el rechazo de las preguntas trampa.

Regla 5. Cuando el retriever trae solo una parte, el modelo lo dice.

Mini-proyecto RAG · PLN

El prompt va en inglés porque las preguntas, el corpus y las respuestas ideales están en inglés. Las citas con número de chunk permiten ver de dónde sale cada dato; se quitan antes de pasar la respuesta a RAGAS. La llamada usa Claude Haiku 5.5 con effort medium, su valor por defecto.
