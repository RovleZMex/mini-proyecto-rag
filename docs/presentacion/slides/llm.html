El LLM: costo, latencia y privacidad

CriterioMedición en este proyectoImplicación
CostoUSD 0.004 por 12 respuestas con Haiku 5.5Despreciable; no justifica un modelo local
Latencia1 a 4 s por respuestaAdecuada para una consulta interactiva
CalidadFaithfulness 0.97; el error principal es del retrievalUn modelo más grande no resuelve lo que falta
PrivacidadEl corpus son notas públicas de RiotUna API externa no expone nada sensible

Elección: una API de un modelo pequeño (Claude Haiku 5.5). Con documentos privados, la conclusión cambiaría hacia un modelo local o un proveedor con garantías de retención de datos, a costa de más latencia y mantenimiento.

Mini-proyecto RAG · PLN

La decisión se apoya en lo que medimos, no en supuestos. El costo por consulta es una fracción de centavo y la latencia es de pocos segundos. La privacidad es la variable que más cambiaría la decisión en otro dominio: con contratos o expedientes médicos, el texto recuperado no debería salir de la organización.
